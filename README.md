# chat-v2 releases

Installers for chat-v2, built automatically from the private source repository on every push to `main`.

- **Windows:** download `chat-v2-<version>-setup.exe` from the [latest release](https://github.com/pandacover/chat-v2-releases/releases/latest) and run it. The app updates itself from then on.
- **macOS:** download `chat-v2-<version>-universal.dmg` and drag chat-v2 into Applications. Builds are not signed yet, so the first launch needs right-click › Open. When an update is out, the app downloads the new DMG for you.

Installed apps read this repository's releases to find updates, so it holds build artifacts only.
